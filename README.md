# LitYeah - Daily Literary Discovery

A modern web platform that celebrates great books and encourages daily reading habits.

## About

LitYeah is a daily literary discovery platform featuring a visual stack of classic books. Each day showcases a "Book of the Day" with rich content including book history, themes, author background, cultural impact, and reading features.

## Features

### Visual Book Stack
- Growing archive of featured books displayed as an elegant stack
- Today's featured book highlighted with a special badge
- Smooth animations and scrolling

### Book Detail Pages
Each book page includes:
- One-sentence magical hook
- Publication info, page count, and estimated reading time
- Why the book matters
- Major themes and ideas
- Author background
- Historical and cultural context
- Reception then vs now
- Modern cultural impact
- Powerful quotes
- Reading experience notes (tone, style, difficulty)
- Fun facts
- Opening text from the book (public domain works)

### Interactive Features
- **5-Minute Reading Challenge**: Encourages daily reading with a built-in timer
- **Reading Reflections**: Personal journal space stored in local browser storage
- **Shareable Messages**: Copy reading achievements to share on social media
- **Related Products Carousel**: Discover adaptations and collectibles
- **Related Books**: Suggestions for similar works

## How to Use

This is a static website built with HTML, CSS, and JavaScript. No build process or dependencies required!

### Option 1: Open Directly
Simply open `index.html` in your web browser.

### Option 2: Local Server (Recommended)
For the best experience, run a local web server:

```bash
# Using Python 3
python3 -m http.server 8080

# Using Python 2
python -m SimpleHTTPServer 8080

# Using Node.js
npx http-server -p 8080
```

Then navigate to `http://localhost:8080` in your browser.
